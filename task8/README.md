# Задание 8: CI/CD и Jenkins

Цель задания — настроить автоматическую цепочку из трёх Jenkins jobs:

1. `Job_1` получает ветку `master` из GitHub в локальный рабочий каталог.
2. `Job_2` удаляет два демонстрационных файла.
3. `Job_3` восстанавливает удалённые файлы из `origin/master`.

## Безопасность

Jenkins будет удалять и восстанавливать только файлы из каталога `demo`:

- `demo/delete_me_1.txt`
- `demo/delete_me_2.txt`
